## Changes

- **Check for Updates…** moved back to the menu; the Version / Check Now row left Settings (the version is in About).
- After waking from sleep, checks wait for the network instead of marking every service unreachable.
- The menu bar icon's tooltip counts unreachable services as problems and says "No services" when the list is empty.
- Import drops repeated status page addresses.
- A stored configuration that cannot be read is kept aside instead of being overwritten.
- Less work while the menu is closed: it is rebuilt only when opened, and checks run per service.
