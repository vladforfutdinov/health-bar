## Accessibility

- **Keyboard and VoiceOver reach every service in the menu.** The arrow keys move through the services one by one; the selected row lights up and scrolls into view. Return opens its status page.
- **VoiceOver** reads each service — name, status, uptime or the current incident — and a summary on the list, such as "1 of 15 services with problems: Snyk". VO-Space opens the page.
- Refresh, About, Check for Updates…, Settings… and Quit are read by name and now respond to Return and VO-Space.
