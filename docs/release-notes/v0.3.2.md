## Changes

- **Import and Export** in Settings: save the whole configuration as JSON and load it back (an old `services.json` imports too).
- The Settings window can be made taller; it remembers which groups are folded, and focus starts in the list.
- The hint about status pages moved into an ⓘ next to "Services".
- Incidents and uptime history are refreshed hourly, and at once when a service's status changes.
- New list of built-in services: [docs/SERVICES.md](https://github.com/vladforfutdinov/health-bar/blob/main/docs/SERVICES.md).
